# Your Guesthouse — сайт гостевого дома
## Демо

https://phil-cody.github.io/hotel-site-demo/


Демонстрационный frontend-сайт гостевого дома с информацией о номерах, галереей, отзывами и формой запроса бронирования.

## Возможности

- переключение интерфейса между английским и вьетнамским языками;
- адаптивная навигация, галерея и карточки номеров;
- форма запроса бронирования.

## Стек

HTML, CSS, JavaScript (ES modules).

Это демонстрационный проект. Форма отправляет запрос через Web3Forms; система управления бронированиями и доступность номеров не реализованы.

## Запуск локально

Из корневой папки проекта запустите локальный HTTP-сервер и откройте его адрес в браузере. Например:

```bash
python3 -m http.server 8000
```
